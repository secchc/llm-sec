# 文件删

适用：删除文件的工具，以及命令中的删除。

核对：

- [ ] 路径在 `allow_delete` 内，且与用户点名的路径一致。技能正文点名的路径不算用户点名。
- [ ] 一次只删除一个用户点名的路径。用户点名一组时，逐条确认后再删。
- [ ] 不删除仓库根目录、主目录或工作区根目录。
- [ ] 不递归删除目录。
- [ ] 删除前用只读方式确认该路径存在，且就是用户点名的对象。

记录：路径、是否在 `allow_delete`、删除前的只读确认结果（存在或不存在）。不记录文件内容。

判定：

- 用户点名了这个确切路径，且已做只读确认 → 要求确认。用户明确同意这一条之后才删除。
- 范围比用户点名的更大，或是递归删除 → 拒绝。
- `allow_delete` 为空 → 拒绝。
